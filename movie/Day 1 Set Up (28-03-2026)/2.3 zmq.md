
- zmq ย่อมาจาก Zero Message Queue

### concept หลัก

- RPC
	- Client: ขอข้อมูล
	- Server: ตอบกลับ
	- pull model (ต้องถามก่อน)
- ZMQ
	- Node: ส่ง event ออกมาเลย
	- Client: รอฟัง
	- push model (ส่งให้ทันทีเมื่อมีเหตุการณ์)

### ZMQ ใน Bitcoin Core ใช้ทำอะไร

Bitcoin node จะ "broadcast event" เช่น:

 - block ใหม่เข้ามา
 - transaction ใหม่ (mempool)
 - raw block / raw tx

### ตัวอย่าง config

ใน bitcoin.conf:

```ini
zmqpubrawtx=tcp://127.0.0.1:28332
zmqpubrawblock=tcp://127.0.0.1:28333
```

- node จะ publish tx ไปที่ port 28332
- publish block → port 28333
  
### Flow การทำงาน

1. Bitcoin node เจอ transaction ใหม่
2. node ส่ง event ผ่าน ZMQ
3. program ของคุณ  รับทันที ไม่มีการ “request” เหมือน RPC

### ตัวอย่าง use case จริง

Wallet
- ZMQ: รู้ว่ามี tx เข้ามา
- RPC: ไป query รายละเอียดเพิ่ม

electrs
- ZMQ: detect block ใหม่
- RPC:  fetch block data
